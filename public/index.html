WTC XSP 0DTE V1 is a forward-test model using read-only Tastytrade market data. SPY drives the entry model; ES contributes a capped confirmation layer. Entries use the modeled XSP option ask and exits use the bid, so the primary P&L includes the quoted spread. No orders are placed. V1 rules are intentionally frozen until a useful sample exists.
