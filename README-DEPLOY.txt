Windows quick deploy:
1. Unzip this folder.
2. Make sure Node.js LTS is installed.
3. Double-click deploy-windows.bat.
4. Approve/sign in to Netlify if prompted.
5. When deployment finishes, open the target site.
6. Click ENABLE PUSH and then SERVER TEST.

For iPhone background push:
1. Open the live site in Safari.
2. Share -> Add to Home Screen.
3. Launch the installed WTC MNQ app from the Home Screen.
4. Enable push inside the app.
5. Run SERVER TEST.

The server-side engine checks once per minute during weekdays and only sends actionable BUY MNQ / SELL MNQ transition alerts. The dashboard itself polls status roughly every 30 seconds.
